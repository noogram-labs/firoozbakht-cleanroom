# Red-team corpus

27 statements adjacent to Firoozbakht's conjecture, **every one of them false or
ill-formed**, run through the same Lean toolchain as `lean/`. The corpus exists
to test one claim the formal leg otherwise asserts without evidence: *the
checker rejects what it should reject*.

Read [`coverage-report.md`](coverage-report.md) first. The main finding is in §4:
**a green `lake build` is not the acceptance criterion** — three entries compile
and one of them also passes a clean axiom audit.

## Run it

```bash
bash corpus/run_corpus.sh      # from the repo root; ~91 s on a warm cache
cat corpus/results.tsv
```

Exit 0 iff every entry behaves as `manifest.json` says it must — including the
four that are *supposed* to compile.

## Layout

| Path | Must | Why |
|---|---|---|
| `refutations/` | **compile** | each theorem proves `¬ S` for a corpus statement `S`. Strongest evidence available: not "an attempt failed" but *no attempt can succeed* |
| `attempts/` | **fail** | one file per entry — the most plausible wrong proof a careless author would write. One file each so a failure cannot be masked by a neighbour |
| `audit/` | **compile** | `lake build` accepts them; only `#print axioms` catches them. That is the finding |
| `undetected/` | **compile, clean audit** | no gate in this run fires at all. That is a bigger finding |
| `rejected-candidates/` | **compile** | proofs about near-misses that could *not* be entries, because their falsity is as open as the conjecture itself |
| `manifest.json` | — | per entry: statement, `expected_verdict: false`, category, provenance, evidence class, observed result |
| `results.tsv` | — | generated by the runner |

## The one rule

Every entry has `expected_verdict: false`. The **evidence** field says how that
is established, and it is deliberately not uniform:

- `refuted` (20) — the negation is proven, no `sorry`
- `rejected` (3) — ill-formed, or unprovable by any means; elaboration fails
- `accepted-but-unsound` (3) — build green; caught only by the axiom audit
- `undetected` (1) — build green, audit clean; caught by nothing automated

## Standing invariant

If a file in `refutations/` or `rejected-candidates/` ever stops compiling, a
definition in `lean/Firoozbakht/` has changed meaning. **That is the alarm
firing, not a bug in the corpus.**
