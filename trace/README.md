# trace/ — always-on trace sidecar

Append-only, read-only-on-`.cosmon/state/` capture of what the cosmon
runtime did for the Firoozbakht MATH-ATTACK polymers. Generated by
`tools/trace_collector.py`. Never hand-edit these files — re-run the
collector to refresh a sweep.

Layout: one subdirectory per polymer (`germ-<id>`), each holding
`events.jsonl`, `briefs.md`, `hashes.tsv`, `manifest.json` (sweep
history), and `collector.log` (one line per sweep). The flat
`events.jsonl` / `briefs.md` / `hashes.tsv` / `manifest.json` /
`collector.log` at this top level are the trace of the first polymer
germinated in this galaxy (`germ-20260725-0a263cae`), kept flat for
backward compatibility with sweeps taken before the multi-polymer
layout existed.

Per-polymer traces to date:

- `germ-20260725-0a263cae` — see the flat files at this directory's root.
- `germ-20260725-6cf650df` — see `germ-20260725-6cf650df/`.

Each `manifest.json` records, per sweep: the source `run_dir` and
`state_root` read, node count, events seen, events newly written per
destination, and artifact hash/byte totals. `hashes.tsv` is a snapshot
— a file written and deleted between two sweeps is not counted, so
byte totals are a lower bound, never an over-count.
